# 食刻 FoodLens

React Native + Expo + TypeScript 食品标签解读 MVP。iOS、Android 和浏览器共用界面与营养规则。

应用内加入中英文用户协议、隐私政策、健康说明与客服帮助，支持离线阅读。在我的、关于、首次引导和上传提示提供入口；完成引导后主动勾选阅读确认，升级保留历史并提示新文档。云端上传仍独立授权，可以单独关闭后续授权而保留历史。当前运营信息未齐，正文明确标为草案；不代表已完成上架或订阅接入。详见 [版本记录](docs/release-0.4.3.md)。

## 0.4.2 更新

修复新拍照识别成功后，记录仍可能显示默认图的问题：在上传前从仍有效的图片引用生成本地JPEG缩略图，并与对应食品结果一起保存。超过16,000字符时继续降低缩略图尺寸，不再直接丢弃；图片引用不可用时使用实际上传JPEG重试。列表从JPEG头读取比例，尺寸读取失败不再把可显示的照片误换成默认图；图片按原比例显示并保留12px圆角。

旧版已保存的缩略图与偏好继续保留。历史记录当时没有保存照片的，无法自动补回，继续使用默认包装图；新拍照/相册识别会保留对应照片。缩略图只存本机，清除本地数据时一起删除。

## 0.3.3 更新

拍照/选图先以最高质量读取，再在上传前分级JPEG压缩：优先保留2400长边，质量0.86→0.76；仅在必要时降到2048/1800，目标750KiB，硬上限1.8MB；小图不放大。界面预览实际上传图，并显示其尺寸和KB数，裁剪原图仍可重新调整。压缩在连接探测之前本地完成，不上传未获同意的图片。

浏览器备用入口已发布到 `https://foodlens-recognition.aidaole.workers.dev/`，与APK使用同一代码和识别接口。App连接错误时可打开浏览器继续。原生和浏览器记录分别存储；如手机浏览器能连接而App不能，可检查VPN按应用代理设置。浏览器也不能连接时，压缩不能解决域名或路由问题，需要用户手机访问反馈进一步定位。

同来源/会话每日额度改为16次，全局仍25次，给开发与真机复测留出空间；仍保留Workers Free计划。

### 0.3.2 已有修复

修复识别等待与错误分类：先探测服务连接，断线时只重试探测一次；网络连接/图片处理/云端识别分别设置时限并显示阶段。移除统一90秒取消；连接请求限10秒、图片准备30秒、模型请求最多180秒。主动取消、连接失败、图片处理超时和模型等待超时分别提示，保留照片；不自动重复消耗额度的模型请求。

用户提供的1280×1211真实巧克力标签已线上识别成功，并在390×844浏览器通过相册→裁剪→连接检查→识别→结果全流程。该验证不能代替用户手机网络或所有配料小字准确率验证。

引导页压短并保留可滚动空间；记录与我的页面移除顶部栏。云端识别的 App 流程和 Cloudflare Worker 已实现，包含图片压缩、首次发送说明、自动识别、取消/重试、字段校验、单位换算、原文核对、真实结果记录和收藏。

**真实云端识别已开启。** Cloudflare Workers AI 托管 Google Gemma 4，服务地址为 `https://foodlens-recognition.aidaole.workers.dev`。裁剪完成后自动识别；第一次发送前显示隐私说明。模型失败或标签不清晰时提示重试/补拍，不用示例代替真实结果。后端配置见 `worker/README.md`。

## 体验

使用 Node.js 22.13 或更新版本：

```sh
npm install
npm run web
```

可运行 `npm run build`、`npm run preview` 打开生产预览。

当前工作环境默认 Node 18，已使用 Codex 自带 Node 24 完成开发；一键启动脚本会自动优先选择兼容的运行时。

```sh
./scripts/start-local.sh
```

可体验首次引导、拍照入口、图片裁剪、三种示例结果、每份/每100g/整包换算、收藏、搜索记录和饮食偏好。手机浏览器可在同一网络访问启动日志中的地址；Android 可直接安装下方体验 APK。

真实标签照片经裁剪和压缩后发送至 Cloudflare，识别配料、标注基准和营养数值；缺失值显示“未标注”。服务器不保存照片或识别正文，设备保存识别文字、结果与压缩缩略图。示例包装和示例数据仍单独标注为演示。

## 产品与界面

奶油白 + 青柠绿 + 深墨绿；手机底部导航、桌面侧栏。首次启动展示三页引导，完成后进入拍照。底部只有拍照、记录、我的三个真实 Tab，切换保留页面状态，不形成返回栈。顶部栏随内容滚动离开视野；手机分析页优先展示热量与脂肪。没有账号注册或付费入口。

- 配料解释；明确区分过敏原与“可能含有”。
- 能量、总脂肪、饱和脂肪、碳水、蛋白质、纤维、总糖、添加糖、钠。
- 根据食用份量计算成人参考日值；不使用任意健康分数。
- 脂肪、血糖、血脂、血压关注设置；匹配已知过敏原时优先提醒。
- 最多50条本地体验记录；收藏、搜索、清除数据。
- 拍照或选图自动进入裁剪；支持拖动选区、四角缩放、重置与重新裁剪。
- 我的页面可重看引导；升级保留原有偏好、记录和收藏。
- 标签小课堂、参考依据、数据与隐私说明。

单个食品不能代表整体饮食；提示不能诊断疾病或给出疾病食用许可。当前 DV 使用美国 FDA 参考值，明确区别于中国 NRV 和个体饮食目标。

## Android APK 体验包

当前体验版为 `outputs/FoodLens-0.4.3-preview.apk`（versionCode 10），支持 Android7.0+ 的 arm64-v8a 与 armeabi-v7a。使用本地测试签名，应用代码内置，无需 Expo Go 或 Metro 服务器；真实识别需要联网。

签名校验通过，在 API36 ARM64 模拟器安装与冷启动成功；启动后进程保持运行，没有 ReactNativeJS/AndroidRuntime 错误日志。手机相机仍需用户在真机体验。

本机重复打包：

```sh
./scripts/build-apk.sh
```

原生工程由 Expo prebuild 生成并被 Git 忽略；`outputs/` 中保留APK、校验和与安装说明。以后正式商店发布需独立配置发布签名。
