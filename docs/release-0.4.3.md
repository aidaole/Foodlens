# FoodLens 0.4.3 协议接入体验版

版本 0.4.3，Android versionCode 10。已加入应用内中英文用户协议、隐私政策、健康信息说明和帮助支持；正文随安装包保存，可离线阅读。「我的 → 协议与隐私」、关于页面、首次引导和云端上传提示都可进入正文。
