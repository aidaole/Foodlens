# Cloudflare 图片识别调研

核查及实测：2026-10-14。用户账号已授权，识别后端已部署；保留Workers Free计划。

## 免费服务是 Workers AI

Cloudflare Workers AI 提供每天 **10,000 Neurons** 免费推理额度，Free/Paid Workers 计划均包含。额度每天 UTC 00:00（北京时间08:00）重置。Free 超额请求失败，使用更多额度需升级 Workers Paid；Paid 的超额推理为 $0.011/1,000 Neurons。部分资源密集模型要求付费方式，不能把所有模型视为免费可用。

这是计算量额度，不是固定拍照次数。输入图像、输入/输出 token、模型决定消耗；必须测量实际请求再估算每天可识别多少张。

来源：[Workers AI 官方价格页](https://developers.cloudflare.com/workers-ai/platform/pricing/)。

## 最终模型与候选实测

最终采用 `@cf/google/gemma-4-26b-a4b-it`。官方支持视觉和多语言处理，Gemma4采用Apache2.0许可。使用JSON模式并关闭思考，保留原文证据；中文和英文测试标签均读取成功。中文1400×1700校验图一次原始模型响应消耗22.65Neurons，这是单个清晰测试图的实测，不能外推为固定日容量。

来源：[Gemma4模型页](https://developers.cloudflare.com/workers-ai/models/gemma-4-26b-a4b-it/)、[模型许可](https://ai.google.dev/gemma/apache_2)。

早期候选Llama3.2 Vision在用户确认后接受条款并测试，中文图产生非JSON输出并补出未标注的营养值，被校验拒绝，未作为有效结果显示。最终服务不使用该候选。

候选不等于最终采用。模型能理解图片并不证明它能可靠读取中文包装小字。需以真实中文、英文包装验证配料文本、单位、每100g/每份基准和脂肪数值。反光、曲面、低清晰度、标签遮挡应返回补拍提示，不能编造缺失营养值。

## 已接入链路

App 拍摄/选择图片 → 设备端缩放与去除不必要信息 → HTTPS Worker → Workers AI 提取标签结构化字段 → 字段和单位校验 → 前端确定性换算与提醒 → 本地历史。

- App 不包含 Cloudflare API token。Worker 使用 AI binding，凭据留在服务端。
- 相机页仍只需要一次拍照；成功后直接跳结果。缺失字段才请求补拍。
- 识别源文本与模型提取字段同时保留供用户核对；不能输出虚构“98%准确率”。
- 能量区分 kJ/kcal，采用 1 kcal = 4.184 kJ；g/mg、100g/100mL、每份/整包不能混用。
- 添加糖和饱和脂肪可能不在标签上；使用 `null` 并显示“未标注”，不自动当0。
- 视觉模型只提取内容；医学相关提醒来自经过审查的规则，不让视觉模型自行给诊断或用药建议。
- 服务端增加身份/匿名会话控制、图片大小限制、请求频率限制、超额与模型繁忙提示，防止免费额度被滥用。CORS 不能代替认证或配额限制。
- 默认瞬时处理图片，不建立照片库；处理方、保留时间和隐私条款在发送前明确。若以后保存历史照片，另行设计存储与删除。

API：先获取匿名签名会话，再 `POST /v1/recognize`，发送内嵌JPEG，不发送疾病偏好。成功返回结构校验后的Food，包含原文、配料、过敏原、营养、份量、基准与证据。失败返回明确错误码；校验失败不会显示成功结果。原生App只内置公开接口地址，没有账号凭据。
